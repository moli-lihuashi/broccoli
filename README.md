# Broccoli · Lando Norris 中文粉丝站

> 2025 赛季迈凯伦 F1 车手 **Lando Norris（LN4）** 的沉浸式中文粉丝主页。

**在线预览：** [https://moli-lihuashi.github.io/broccoli/](https://moli-lihuashi.github.io/broccoli/)

纯静态前端项目，无需构建工具，克隆后直接打开即可运行。

---

## 项目简介

这是一个非官方的 F1 车手粉丝站，围绕 Lando Norris 的职业生涯、赛道表现、生活方式与车迷互动展开。页面以深色赛车美学为基调（McLaren 标志性的荧光绿点缀），用滚动叙事串联成绩数据、历史时间线、赛车规格、赛季日程，并内置可玩的游戏中心与车迷投票。

**技术栈：** HTML5 · CSS3 · 原生 JavaScript（无框架）

| 技术点 | 用途 |
| --- | --- |
| CSS Custom Properties + 动画 | 明暗主题、极光背景、滚动揭示 |
| Canvas / SVG | Hero 粒子、赛道图、赛季走势图 |
| Web Audio API | 游戏音效与 Team Radio 彩蛋 |
| Intersection Observer | 懒加载、数字滚动、版块进入动画 |
| localStorage | 主题偏好、游戏成绩、留言、投票、预测 |

**视觉规格：**
- 主题色：荧光绿 `#00FF87`，辅助橙 `#FF6B00`，背景近黑 `#0A0A0A`
- 字体：`Inter`（正文）+ `Space Grotesk`（展示标题）
- 默认深色模式，支持一键切换浅色

## 功能一览

### 内容版块

- **Hero 首页** — 大标题、粒子背景、下一场比赛倒计时
- **签名展示** — SVG 路径描边动画 +「McLaren F1 Since 2019」
- **个人宣言** — 逐词揭示文案
- **职业数据** — 分场次 / 领奖台 / 杆位 / 发车次数滚动计数
- **视觉故事 & 画廊** — 瀑布流图片墙，点击进入全屏 Lightbox
- **F1 发展史** — 横向时间线，赛车随滚动前进
- **赛道上** — 2024 赛季成绩、车手数据对比
- **MCL38 技术规格** — 交互热点 + 参数进度条
- **赛道外** — 生活方式、社交媒体动态、头盔名人堂
- **合作伙伴 & LN 商店** — 品牌墙与周边展示
- **2025 赛季日历** — 分站赛程
- **积分榜** — 车手 / 车队积分切换
- **赛季走势图** — Canvas 绘制的赛季趋势曲线
- **车迷投票** — 本地记票，可重置
- **粉丝留言** — 表单提交，本地持久化
- **视频区** — F1 相关视频入口

### 互动与游戏

| 模块 | 说明 |
| --- | --- |
| 反应测试 | 模拟起步灯，记录最佳 / 平均反应时 |
| F1 知识问答 | 多题计分，支持重开 |
| 成就徽章 | 根据互动行为解锁，累计积分 |
| 排行榜 | 本地成绩排行 |
| 比赛预测 | 杆位 / 冠军 / 名次 / 安全车预测，统计准确率 |
| Team Radio | 悬浮按钮彩蛋，播放 Lando 经典语音 |

### 体验细节

- 开场加载动画与进度条
- 自定义光标、滚动进度条、版块指示器
- Hero 悬停圆形揭示头盔图
- 明暗主题切换（记忆偏好）
- 移动端底部快捷导航栏
- 键盘导航与快捷键帮助
- 图片懒加载、`prefers-reduced-motion` 降级
- Skip to content、ARIA 标注等可访问性支持

### 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `↓` / `J` | 下一个版块 |

| `?` | 显示 / 隐藏快捷键帮助 |

## 项目结构

```
broccoli/
├── index.html              # 页面主体（结构 + SEO / 结构化数据）
├── complete_merged.css     # 合并后的完整样式（~96 KB）
├── complete_merged.js      # 合并后的完整脚本（~92 KB）
└── Photoshot/              # 图片与视频素材
    ├── 1.mp4
    ├── 1.png … 19.jpeg
    └── …
```

脚本与样式均已合并为单文件，按功能分段组织（全局工具 → App 核心 → 滚动 / 动画 → 时间线 → 主题画廊 → 粉丝留言 → 游戏与成就 → 积分榜 / 预测 → 投票 / 视频 → 可访问性）。

## 本地运行

无需安装依赖，任选一种方式：

```bash
# 方式一：直接用浏览器打开
start index.html          # Windows
# open index.html         # macOS
# xdg-open index.html     # Linux

# 方式二：起一个本地静态服务（推荐，避免部分浏览器的本地文件限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署（GitHub Pages）

本仓库已启用 GitHub Pages：

1. 打开仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选择 `main`，目录选择 `/ (root)`
4. 保存后等待构建完成，访问  
   `https://<username>.github.io/broccoli/`

推送 `main` 分支后，Pages 会自动更新。

## 数据说明

页面中的成绩、积分、赛程等为**写死在前端的数据快照**，以 2024–2025 赛季相关介绍为主，并非实时 API。若需更新，直接修改 `index.html` 或 `complete_merged.js` 中对应的数据节点即可。

粉丝留言、投票、游戏成绩与预测记录保存在浏览器 `localStorage`，不会跨设备同步，清除站点数据会一并清空。
